Super compact stats for your fleet

Your Mac and your Linux servers, in the space of three menu bar icons.

Menu bar space runs out fast, and a system monitor is often one of the widest things in it. Squished is a free, open-source monitor for macOS that shows CPU, memory and disk for your Mac and the Linux machines you already SSH into (a home server, a NAS, a VPS). Nothing gets installed on the servers.

Get it on GitHub Free, MIT license. macOS 14 or later.

How much menu bar space it takes

Every app wants a spot in the menu bar, a MacBook's notch takes the middle, and whatever doesn't fit drops out of sight. A system monitor is often one of the widest things up there. Squished was built to take as little of that room as it can: about 40 points for one Mac and 83 for three machines.

Monitors that can watch several machines usually put a single status icon in the menu bar and keep the numbers in a dropdown.

What you get

  • Three bars per machine. CPU, memory, disk. A free-space number appears under a disk only when it's getting full.
  • Nothing to install on your servers. Squished uses your existing SSH setup. No agent, no daemon, no extra open ports.
  • Quiet until it matters. Bars change colour only for real trouble: memory pressure, a nearly full disk, CPU pinned for a while.
  • Click for the detail. Top processes by CPU and memory, five minutes of history, network rates, disk partitions, uptime, and btop on any machine in one click.

Reading the menu bar

Each machine gets a short label and three bars: CPU, memory and disk, with a second disk bar when a machine has two disks. The number under the Mac's disk is free space in GiB, shown because less than 30% is left. On the right are this Mac's upload and download rates. You choose which machines appear in the menu bar; the rest stay in the panel.

Monitor Linux servers over SSH, with nothing to install

  • On the Mac, Squished reads macOS's own counters. Nothing runs as root.
  • For each remote machine it keeps one SSH connection open and runs a small shell and awk script that reads /proc every two seconds by default and sends back a compact frame, typically under 2 KiB.
  • The script is sent each time it connects, so there is nothing on the server to install or update.

Remote machines need Linux with /proc, sh, awk and standard utilities such as df. The sampler is tested on Ubuntu with gawk, mawk and BusyBox awk, including data from a Synology NAS.

Install

Squished is built from source for now. The app runs on macOS 14 or later; building needs Xcode 16 or another Swift 6 toolchain.

git clone https://github.com/andrewk17/squished.git
cd squished
Scripts/package-app.sh --install
open /Applications/Squished.app

Then open Settings → Hosts and add an alias from your ~/.ssh/config. The host needs to accept a key login without a password prompt. The README has the details.

Is Squished for you?

Want detailed graphs for just your Mac? Stats does more. Want a dashboard for a whole rack of servers? Beszel does more. Squished is for glancing at a handful of machines without leaving the menu bar.

Questions

What is Squished?

Squished is a free, open-source menu bar app for macOS. It shows CPU, memory and disk for your Mac and the Linux machines you SSH into, side by side in one compact menu bar item. Click it for top processes, history, network rates and disk partitions.

What can I do when my Mac's menu bar is full?

macOS hides menu bar items that don't fit, and a MacBook's notch leaves less room to begin with. You can remove items you don't need by holding Command and dragging them off the bar, use a menu bar manager such as Ice to tuck some away, or switch to apps that take less room. Squished is the last kind: a system monitor about 40 points wide for one Mac.

Does Squished install anything on my servers?

No. Squished uses your existing SSH setup and sends a small shell and awk script over the connection each time it connects. There is no agent, no daemon and no extra open port on the server.

What do the remote machines need?

Linux with /proc, sh, awk and standard utilities such as df, and an SSH key login that doesn't prompt for a password. The sampler is tested on Ubuntu with gawk, mawk and BusyBox awk, including data from a Synology NAS. Remote Macs are not supported yet.

How much menu bar space does Squished use?

About 40 points for one Mac and 83 points for three machines, network rates included. That was measured on macOS 27.2 in November 2026. For comparison, MenuMeters used 41 points, Stats 65 and Vorssaint 111 to show one Mac in their most compact setups.

How is Squished different from Stats or iStat Menus?

Stats and iStat Menus go deep on the Mac they run on, with detailed graphs and sensors. Squished goes wide: a few numbers for several machines at once, in less menu bar space. If you only care about one Mac and want every detail, Stats does more.

Is Squished free?

Yes. Squished is open source under the MIT license, and the source is on GitHub.

Does Squished send my data anywhere?

No. The app has no analytics and makes no network requests of its own. The only connections are the SSH sessions to the machines you add.

Which versions of macOS does Squished run on?

macOS 14 or later. For now you build it from source, which needs Xcode 16 or another Swift 6 toolchain.
